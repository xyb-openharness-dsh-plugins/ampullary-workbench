# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：壶腹部腺癌患者与家属照护者；含术前减黄等待手术者、胰十二指肠切除（Whipple/PPPD）术后随访者、复发转移后寻求临床试验者；患者组织志愿者协作使用

场景：壶腹部腺癌的定性依据（活检/术中冰冻/EUS-FNA 与病理报告）留档；术前胆道引流（PTCD/ERCP 支架）与减黄过程记录；胰十二指肠切除术后并发症（胰瘘、胃排空延迟、胆肠吻合口狭窄）与随访节奏；黄疸指标、营养与体重、胰酶替代、血糖变化各自成线；复发监测与影像对照；临床试验档案建立—检索—结果匹配；罕见病与慢特病救助材料准备

核心流程：
1. 选择本机资料目录，导入病理/影像/化验/出院记录
2. 核对候选信息，建立定性依据档案与分期原文（不换算分期）
3. 记录术前引流减黄或术后随访的指标线，各自独立不合并
4. 整理随访节奏与并发症事件，生成复诊准备材料
5. 建立临床试验档案并检索、按字段重合度查看匹配结果（非入组资格）

完成结果：得到来源可追溯、可核对的个人病程档案：定性依据与分期原文、术前引流与减黄记录、术后并发症与随访节奏、黄疸营养代谢趋势、复发监测影像对照、临床试验候选清单；所有候选信息经用户核对入档，不提供诊断与治疗建议、不判断入组资格

初始布局选择：business-first
