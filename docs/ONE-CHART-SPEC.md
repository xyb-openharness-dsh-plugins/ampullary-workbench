# 小壶宝 AmpuPal 一图秀开发规范（项目实例）

> 通用规范见 `docs/16-ONE-CHART-SPEC.md`；本文件只填**本项目的具体口径**，不复制规范正文。
> 状态：G2 原型已实现，探针 51 条断言全通过；待用户签认。

日期：2026-10-26。实现入口：`prototypes/v0.2/index.html`（`app.js` 的 `chartSVG() / seriesScale() / pinBar()`）。指标来源文档：`docs/SPEC.md` §四 数据实体、`demo/demo-source.mjs`。

## 1. 三个合同

| 合同 | 本项目口径 | 写在哪 |
| --- | --- | --- |
| 可比性 | 7 条线**没有一条能同轴**：胆红素 μmol/L、CA19-9 U/mL、白蛋白 g/L、体重 kg、血糖 mmol/L、HbA1c %。它们只在"同一天发生过什么"这一层可以并排，纵向位置不可比。断线规则：换检验科 / 换检测方法 / 换计量单位（如体重从 kg 换成斤）必须断线并新起一段，不复用旧点插值。 | SPEC §二 ADR-2 / UI-DESIGN |
| 归一化 | 每条线按**自身全部记录**的 min/max 归一化（不是时间窗内的），零跨度兜底 `span = hi - lo \|\| max(\|hi\| × 0.08, 1)`。实现：`seriesScale(m)`。 | `app.js: seriesScale()` |
| 事实源 | 唯一来源 `demo/demo-source.mjs` → `scripts/build-prototype-data.mjs` → `prototypes/v0.2/demo-data.js`。一图秀、指标卡、四个关键数字、摘要、导出全部读这一份，页面里没有第二处写死的业务数值。G3 落库时同一份源生成 `metric` 表并逐点 `deepStrictEqual`。 | `demo/` + `scripts/build-prototype-data.mjs` |

## 2. 指标清单

| 编码 | 名称 | 分类 | 单位 | 精度 | 变化口径（绝对/百分比） | 可比性分组 |
| --- | --- | --- | --- | --- | --- | --- |
| `tbil` | 总胆红素 | 术前减黄段 | μmol/L | 0 位 | 绝对（μmol/L） | G-BILI |
| `dbil` | 直接胆红素 | 术前减黄段 | μmol/L | 0 位 | 绝对 | G-BILI |
| `ca199` | CA19-9 | 肿瘤与营养 | U/mL | 0 位 | 绝对（≤2 倍写绝对，>2 倍可补倍数并在标签注明"倍数不是判读"） | G-TUMOR |
| `alb` | 白蛋白 | 肿瘤与营养 | g/L | 1 位 | 绝对 | G-NUTRI |
| `weight` | 体重 | 肿瘤与营养 | kg | 1 位 | 绝对 kg（**不用百分比**：康复期体重变化要看实际掉了几公斤） | G-NUTRI |
| `glu` | 空腹血糖 | 代谢 | mmol/L | 1 位 | 绝对 | G-META |
| `hba1c` | HbA1c | 代谢 | % | 1 位 | 绝对 | G-META |

- 指标总数：**7**（上限 30，未触发分组搜索；分组只是显示分组，不是等级）
- 默认选中：**4 条** —— `tbil` / `ca199` / `alb` / `weight`（与 `state.sel` 一致）
- 颜色：术前减黄段琥珀两档 `#a9761c` / `#c98a2e`；肿瘤与营养 `#8b5e83` / `#2f6f66` / `#4a7a9b`；代谢 `#a3241b` / `#8a5a0c`。**颜色不是唯一区分手段**：图例每项同时给短名与单位，圆点带 `aria-label` 与 `<title>`。
- 未检测与缺失**不插值补点**（左栏有常显句）。

## 3. 治疗节点

| 类型 | 呈现 | 数据来源 | 备注 |
| --- | --- | --- | --- |
| 术前减黄（ERCP 支架 / PTCD） | 独立色带（`drain`，琥珀 `#a9761c`，透明度 .45） | `demo-source.mjs → bands` | 起止日期；与总胆红素同色系，但只表示"这段时间带着支架" |
| 手术 | **单日事件**：条宽 4px 的短条 + 图例写日期 | `bands`（`from === to`） | 时点事件，不占 lane；**条上不写字**（4px 宽写不下），标签走 `.band-legend` |
| 术后住院 / 恢复期 | 独立色带（`recovery`，紫 `#8b5e83`） | `bands` | 起止日期 |
| 关键事件（影像、报告、复查） | 贯穿竖虚线 + 顶部标签 | `marks` | 两行交错、最小间距 74 viewBox px；放不下只留竖线 + `<title>` |

治疗条固定占 `y = 36..45` 一行，**不参与归一化**：关掉后指标路径 `d` 与所有点 `cy` 都不变。

## 4. 状态默认值

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 时间范围 | `all`（全部） | 另有 `6m` / `3m`；切换后副标题与点数同步 |
| 缩放 | 无滑杆（宽度铺满 `CX0=62 → CX1=954`） | 见 §8 已知偏离 D1 |
| 显示内容 | 治疗条 **开** / 事件竖线 **开** / 末点数值 **常开** | 治疗条开关在图上图例行，`aria-pressed` 由 checkbox 表达 |
| 固定详情 | 空态占位条（虚线框 + 一句提示） | 点选后才出现读数，清除后回到空态，版面不跳动 |

## 5. R1–R12 逐条核对

| 规则 | 结论 | 证据（断言语句） | 偏离理由 |
| --- | --- | --- | --- |
| R1 独立归一化 + 不可比说明 | 符合 | 探针「每条线都落在绘图区内（132–366）」「图上写明"不代表数值可比"」 | |
| R2 单点不连线 + 空态 | 符合 | 单点走 `single` 文案「只有 1 次记录，暂不连线」；窗内无点返回 `.empty` 空态（`hba1c` 3 点、`glu` 5 点可验） | |
| R3 治疗条分层 | 符合 | 探针「关掉治疗条后指标路径完全不变」「关掉后治疗条确实不在了」 | |
| R4 只标末点 + 避让 | 符合 | `lastPos` 按 y 排序后 13px 下限避让、右端 `nearRight` 左锚定；事件标签 74px 交错 | |
| R5 变化口径按类型 | 符合 | 体重/白蛋白用绝对 kg/g；指标卡 delta 写「与上次 ±X」不写百分比 | |
| R6 `pathLength=1` 动画 | 符合 | 探针「曲线带 pathLength=1（R6 描线动画前提）」 | |
| R7 ≤4 指标 + 可滚动 + 折叠 | 符合 | 探针「选满 4 条后第 5 条回弹」「回弹时给出提示『最多同时选 4 条』」；左栏 `.rail` 独立滚动 | |
| R8 时间窗/缩放/图例一致 | 符合 | chips `aria-pressed` 单值；图例每项带单位；`#bands` 只控制治疗条 | 缩放滑杆未做，见 D1 |
| R9 固定详情 + 回源 | 符合 | 探针「点圆点后读数条给 值 + 单位」「读数条给日期」「读数条给来源（回源）」「清除后回到空态」 | |
| R10 `minmax(0,1fr)` + 独立滚动 | 符合 | `.timeline-main` 用 `minmax(0,1fr)`；820px 无横向溢出 | |
| R11 减少动效保留终态 | 符合 | `@media(prefers-reduced-motion:reduce)` 把 `stroke-dasharray/dashoffset` 归零、关掉 pageIn | |
| R12 可访问性 | 符合 | 圆点 `role="button" tabindex="0"` + Enter/空格等价点击；`svg` 有 `role="img"` 与 `aria-label`；读数条 `role="status" aria-live="polite"` | 圆点无"下一点/上一点"方向键遍历，记入 BACKLOG |

## 6. 验收断言 C1–C12

| 编号 | 断言 | 结果 | 实测值 |
| --- | --- | --- | --- |
| C1 | 量纲差异大的两指标都占满纵向区 | 通过 | TBIL 198→15 与体重 52.0→58.5 各自铺满 132–366 |
| C2 | 单点不连线 | 通过 | 单点序列 `d === ''`，只渲点与文案 |
| C3 | 空窗口有空态 | 通过 | `近 3 个月` + 只选 `hba1c` 时返回 `.empty` |
| C4 | 关治疗节点曲线不变 | 通过 | 探针逐条比对 `d` 字符串完全相等 |
| C5 | 每序列只有一个数值标签 | 通过 | 只有 `lastPos` 末点 tag 一处（`delta-tag` 数量 = 选中线数） |
| C6 | 标签不越界 | 通过 | `over` 回拉：末点标签整体上移到 `CY1 + 2` 以内 |
| C7 | 康复类用绝对值 | 通过 | 体重、白蛋白 delta 均为绝对量 |
| C8 | 时间窗联动 | 通过 | 切 `3m` 后点数 12→4（tbil），chips `aria-pressed` 单值 |
| C9 | 390 宽无横向溢出 | 通过 | 820px 实测 0px；390px 单列布局 |
| C10 | 减少动效下曲线可见 | 通过 | 媒体查询下 `stroke-dashoffset:0`，线全显 |
| C11 | 翻转不位移 | 通过 | `.mcard` 固定 186px，`preserve-3d` 只转不缩放 |
| C12 | 翻转状态独立 | 通过 | `state.flip[code]` 逐卡布尔，与 `aria-pressed` 同步 |

## 2026-10-25 增补（从 CLL 小淋宝 v0.2.0 回收：用户指定的左栏控制版式）

用户原话：「一图秀=左栏（时间范围 chips + 分组指标勾选即时更新 + 显示开关）+ 每条线按自身范围缩放 + 图例带全期区间 + 点选 pin 显示数值/来源」。

| 要素 | 规范 | 本项目落点 | 判据 |
| --- | --- | --- | --- |
| 布局 | 左栏 sticky（232–268px）+ 右栏图；<980px 单列、左栏 `position:static` | `.overview` 两列 / `.rail{position:sticky;top:76px}` / 900px 下 `position:static` | 窄版无横向滚动（实测 0px） |
| 时间 chips | `aria-pressed` 单值 | `全部 / 近 6 个月 / 近 3 个月` | 切换后点数变化、副标题同步 |
| 分组勾选即时更新 | 分组、上限 4、选满回弹并提示 | `catOrder` 三组 + `state.sel` 上限 4 + toast | 探针两条断言锁住 |
| 显示开关 | 治疗节点独立泳道 | `toggle-bands` + `#bands` | 关掉后 `d` 与 `cy` 全不变 |
| 每线自身缩放 | 取该指标**全期** min/max | `seriesScale()` | 切时间窗线形不跳变 |
| 图例带全期区间 | 色点 + 名称 + 区间 + 点数 | 图例给短名与单位；区间放在读数条与卡背 | 本版只给单位，**全期区间**未放进图例（见下） |
| 点选 pin | 值 + 单位 / 日期 / 来源 / 清除 | `.pinbar` + `role="status"` | 探针四条断言锁住 |
| 刻度 | 按像素间距抽稀 | `monthTicks()`：>7 个则隔一取一 | 5–7 个标签不重叠 |
| 空态 | 无记录整块空态 / 窗内无点提示 | `.empty` | DOM 无空 `<svg>` |

> 图例缺口记入 BACKLOG：图例当前是「色点 + 短名 + 单位」，全期区间在读数条与卡背能看到，但没有并排在图例里。下一版补 `min–max · n` 三个字场。

实现参照：cll-workbench `prototypes/v0.1/app.js` 的 `chartSVG()/lineScale()/pageOnechart()`。
