# 场景（S1–S12）· 壶腹部腺癌 小壶宝 AmpuPal

日期：2026-10-26。每条写清：谁、在什么时候、想回答什么、工作台给什么、**不给什么**、落在哪一页。
场景来源：公开患者叙述与文献中的路径共性（0 次一手访谈，如实声明）；不冒充患者原话。

## S1 · 黄疸两周，刚做完 ERCP 放了支架，还说"可能是壶腹部的"

- **谁**：63 岁女性，皮肤发黄、尿色深，总胆红素 198 μmol/L，ERCP 塑料支架置入后第 3 天。
- **想回答**：支架放了胆红素能降多少？降多久才手术？这几天该记什么？
- **给**：引流事件卡（方式/日期/侧别/支架类型）、胆红素线（每次值 + 抽血日 + 距引流第几天）、"记录入口"提示。
- **不给**："减黄有效/无效""可以手术了""支架该换金属的"。
- **落点**：术前减黄 / 3.1 引流事件、3.2 胆红素线。

## S2 · 病理报告到手，第一次看到"肠型"

- **谁**：女儿把病理报告拍照发给家人，报告写"壶腹部中分化腺癌，肠型，浸润至十二指肠固有肌层，未累及胰腺"。
- **想回答**：肠型是什么意思？浸润到固有肌层是 T 几？和胰腺癌是一种病吗？
- **给**：病理卡（亚型三选一 + 报告原句照录）、免疫组化表（CK7/CK20/CDX2/MUC1/MUC2/MUC5AC 原值）、AJCC 8th 壶腹 T 分期的**原文对应行**（不自动填 T）。
- **不给**：自动推算 T 期、给"预后如何"、"相当于胰腺癌几期"。
- **落点**：我的病 / 2.2 病理与亚型、2.3 分期原文。

## S3 · 医生说"先减黄再做 Whipple"，家属查了一晚越查越怕

- **谁**：儿子通宵搜索，"Whipple 手术死亡率""五年生存率"混着看。
- **想回答**：这个手术到底切什么？术前要准备什么？
- **给**：术式解释（PD 与 PPPD 的区别、切除范围、重建三处吻合）、术前准备清单（可勾选 + 可编辑）、问题清单模板（含"能不能保留幽门""要不要术前营养"）。
- **不给**：手术成功率、生存率、"你这个情况适合开"。
- **落点**：手术治疗 / 4.1 手术记录（术前态）、复诊准备 / 10.1 问题清单。

## S4 · 术前 5 天，胆红素降到 62，但发烧了

- **谁**：患者在家 38.6℃，右上腹痛，支架置入后第 12 天。
- **想回答**：这是胆管炎吗？要不要现在回医院？
- **给**：本次与既往体温记录、医生当时交代的原话（原文照录）、就诊提示卡（门槛按病历原文，不由工具定）、联系团队入口。
- **不给**：分诊结论、"先吃退烧药""再观察一晚"。
- **落点**：安全事件（术前减黄 / 3.3 术前评估与时间轴）、复诊准备。

## S5 · 术后第 6 天，引流液淀粉酶高，出院小结还没出

- **谁**：家属从护士站听到"可能有点胰瘘"。
- **想回答**：胰瘘是什么？B 级和 C 级差在哪？要住多久？
- **给**：并发症卡（只记报告原文分级 + 记录人 + 日期）、ISGPS 2016 CR-POPF 定义与 A/B/C 分级**原文解释**（谁的标准、哪一年、哪一版）、既往同类记录。
- **不给**："你这个属于严重""要不要禁食""多久能出院"。
- **落点**：术后并发症 / 5.1 并发症卡、5.2 ISGPS 分级解释。

## S6 · 出院后第一次门诊，带着一张 A4 的出院小结

- **谁**：术后 3 周，体重掉了 7 kg，吃两口就饱。
- **想回答**：体重掉这么多正常吗？是不是胰酶不够？下次复查查什么？
- **给**：体重线（住院基线 + 每周自测）、进食量与餐次记录、胰酶制剂记录（药名/剂量/开始日期，原文照录）、复查项目清单（按出院小结原文列）。
- **不给**："需要加胰酶""营养不良"判定、热量处方。
- **落点**：营养与胰酶 / 7.1 体重线、7.2 胰酶记录；随访与影像 / 8.1 复查日历。

## S7 · 术后 4 个月，第一次复查 CT

- **谁**：CT 报告写"术区未见明确复发征象，肝内见 4 mm 低密度影，建议随访"。
- **想回答**：那个 4 mm 是什么？和上次比变了吗？CA19-9 也升了一点，是不是一起看？
- **给**：影像对照（两次报告原文并列 + 病灶尺寸原文）、CA19-9 线与影像日期同图不同轴（各自归一化 + "不可比"说明）。
- **不给**："考虑转移""基本稳定""复发"任何判读词；不给影像结论。
- **落点**：随访与影像 / 8.2 影像对照、8.3 标志物与影像并列；一图秀。

## S8 · 术后 11 个月，CA19-9 连续两次上升

- **谁**：患者自己发现两次化验单数字在涨。
- **想回答**：涨了多少？多快？下一步医生通常会做什么检查？
- **给**：CA19-9 与总胆红素、白蛋白并列的多线图（各自量纲）、两次值的差值与间隔天数（纯算术）、指南里"复查手段类别"的原文摘录（带版本、页码）。
- **不给**："提示复发""需要尽快化疗""涨得快不好"。
- **落点**：指标趋势 / 6.1 指标总表、6.2 单指标放大；一图秀。

## S9 · 复发后，医生提了一句"可以看看有没有临床试验"

- **谁**：肝转移，二线方案用完后。
- **想回答**：我这情况有什么试验能查？为什么搜"壶腹癌"几乎没有？
- **给**：临床试验三步——① 档案建立（把已确认入库的字段汇总成"匹配用档案"，可逐项勾选是否参与匹配）② 搜索查询（本地快照 + 在线，双通道状态可见）③ 结果匹配分析（分层命中 + 透明匹配分 + 证据行）。
- **不给**："你符合入组""这个试验适合你"；宽口径命中不得写成"符合"。
- **落点**：临床试验 / 9.1、9.2、9.3。

## S10 · 试验页里出现"胆道恶性肿瘤 basket"

- **谁**：检索结果里有一条写"晚期胆道恶性肿瘤（含壶腹癌）"。
- **想回答**：这条算不算我的？它到底要求什么瘤种？
- **给**：宽口径命中卡，**原样写出**"该项入组要求里写的是：胆道恶性肿瘤（含壶腹来源）"，并列出该条的结构化字段原文（分期要求/既往治疗线数/ECOG/器官功能）。
- **不给**：把宽口径改写成"符合"、不替用户判断研究者会不会收。
- **落点**：临床试验 / 9.3 结果匹配分析。

## S11 · 想跟 AI 聊聊这一页，但不想让它替我判断

- **谁**：任何一页，看到一堆数字想说"这些我该怎么跟医生讲"。
- **想回答**：能不能把这一页的事实整理成几句话带去门诊？
- **给**：每页标题行常驻「和 AI 讨论」→ 拉起右侧 AI 对话栏 → 把本页**事实摘要**（值/日期/来源，无判定词）填进输入框 → **不代发**，等用户自己按发送。
- **不给**：自动发送、替用户写"我的病情是…"的结论、在事实摘要里塞任何判读词。
- **落点**：全部 11 页 + 疾病概要整页。

## S12 · 想弄清"壶腹癌到底是个什么病"

- **谁**：刚确诊，家里人都在问"这是什么癌"。
- **想回答**：定义、有哪些规范和指南、世界上大致有哪些治法、这几年有什么变化。
- **给**：疾病概要**整页**（右上角常驻「?」进入，不是弹窗）：定义 → 医学资料规范和指南情况（表格，逐行标原件状态）→ 目前治疗全景 → 发展趋势（只写已发生事实 + 日期/版本）。
- **不给**：预后数字、生存率、"你该选哪种"；原件没拿到就写"未取得原件，据二次来源"。
- **落点**：疾病概要（整页，`docs/DISEASE-PRIMER.md`）。
