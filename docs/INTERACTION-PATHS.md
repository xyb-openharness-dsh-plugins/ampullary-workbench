## 1. 路径条目（六要素，少一要素即该条没写）

### P01 · 减黄期记一个胆红素（S1 / S4）

| 要素 | 内容 |
| --- | --- |
| ID / 场景 | P01 ↔ S1、S4 |
| 入口 | 看板「术前减黄」卡 ·「今天抽血了吗」；导航 `preop > bilirubin` |
| 步骤（AI 默认） | 拍照化验单 → 候选（日期/总胆红素/直接胆红素/ALT）→ 逐项核对 → 确认入档 |
| 步骤（手工收敛） | 卡片「⋯ 更多」→「补一条」→ 4 个字段（日期 · 总胆红素 · 单位 · 备注）+ 数字键盘 |
| 产物 | `metric` 记录 +1；胆红素线末点右移；「距引流第 N 天」重算 |
| 回首页 | 二级页左上「返回」/ 顶栏品牌点一次回一图秀；保存 Toast 内嵌「回到看板」 |
| 失败恢复 | 低精力：只填日期与总胆红素即可保存，其余留 NULL（不补 0）；AI 说错：拒收候选零副作用，回原状 |

## 2. CRUD 双通道矩阵

| 实体 | AI 协助（默认） | 手工（收敛） | 说明与红线 |
| --- | --- | --- | --- |
| `drain_event` 引流事件 | 拍 ERCP/PTCD 记录 → 候选 | 「⋯ 更多」5 字段 | 支架类型不确定写「不清楚」，不猜 |
| `pathology` 病理 | 拍病理报告 → 候选 | 6 字段 | 亚型只照录，不由免疫组化反推 |
| `stage_note` 分期 | 拍报告/门诊记录 → 候选原文 | 3 行并列各 2 字段 | **不生成 T**、不换算、不设 derived 列 |
| `surgery` 手术 | 拍手术记录 → 候选 | 6 字段 | 切缘 R 原文照录 |
| `complication` 并发症 | 拍出院小结 → 候选 | 5 字段 | 分级只照录；解释块属第 ② 层 |
| `metric` 指标点 | 拍化验单 → 候选 | 数字键盘 1–4 字段 | 缺失留 NULL，不补 0 |
| `imaging` 影像 | 拍报告 → 候选 | 5 字段 | 不生成"增大/缩小" |
| `trial_snapshot` 试验 | 在线检索 / 本地快照导入 | —（**红线**：不接受手工凭空录入试验条目） | 试验条目必须有登记号与来源 URL |
| `saved_trial` 收藏 | 结果卡「收藏」 | — | 只存 `(trial_key, saved_at)` |
| `match_profile` 匹配档案 | — | 开关表 | 只存字段引用 + 开关，不存分数 |
